# Express Book Reviews

## Project Name
Express Book Reviews - Online Book Review Application

## Description
This is a server-side online book review application built with Node.js and Express.js as the final project of the IBM "Developing Back-End Apps with Node.js and Express" course.

## Features
- Get the list of all books available in the shop
- Get book details based on ISBN
- Get book details based on author
- Get book details based on title
- Get book reviews
- Register a new user
- Login as a registered user (JWT and session authentication)
- Add or modify a book review (logged-in users only)
- Delete a book review (logged-in users only)
- Retrieve books using Promise callbacks and async/await with Axios

## Technologies Used
- Node.js
- Express.js
- JSON Web Token (JWT)
- Express Session
- Axios
